# residentroom-site

One-page site for Resident Room, Hverfisgata 26, Reykjavík, plus a privacy policy.

- Edit `tools/index.tpl.html` or `tools/privacy.tpl.html`, then run `python3 tools/build.py`.
- Headlines are Bicyclette outlines in `tools/outlines.json`; the licensed font file is not in this repo.
- Hosted on GitHub Pages. Custom domain residentroom.is: add a `CNAME` file and point DNS at GitHub Pages.
